## 修复 MCP 管理页空数据崩溃（Cannot read properties of null reading 'length'）

- 症状：MCP 管理页无数据时（首次使用/未配置任何 MCP），控制台报 `McpPanel.vue:323 TypeError: Cannot read properties of null (reading 'length')` + reka-ui "Deferred DOM node could not be resolved" 伴随警告 + useMcpManagement.ts:139 Vue render 错误。
- 根因：Go 空表/文件不存在时返回 **nil slice** → `json.Encoder` 编码为 JSON `null`（不是 `[]`）。`readMCPServers`/`readGroups`/`readToolStates` 的 ErrNotExist 分支 `return nil, nil`，SQLite 路径 `var x []T` 空表循环不执行也返回 nil。前端 `assignList(servers, null)` 把 ref 置 null → 模板 `.length` 炸。
- 修复（双层）：
  - 前端 `useMcpManagement.ts`：`assignList` 改为 `target.value = next ?? []`（一处兜底所有列表）。
  - 后端 `plugins/admin-api/admin_helpers.go`：`readMCPServers`/`readGroups`/`readToolStates`/`readCapabilityRoutes` 空数据统一返回空 slice（`[]types.X{}`），SQLite 分支 nil 也规范化 → JSON 输出 `[]`。
- lesson：Go 后端列表接口必须保证空数据输出 `[]` 而非 `null`；前端 `assignList` 这类批量赋值也要防御。同文件 `readCapabilityRoutes` 同类坑顺手修了。
- 验证：`go build ./plugins/admin-api/` ✓、`vue-tsc -b` ✓。

## 修复分页组件 NaN/undefined value 报错（DataPagination + shadcn-vue-cdn 语义坑）

- 症状：路由日志页（RouteLogsView）每次自动刷新（setInterval → useListLoader data.value 变化 → 重渲染）控制台刷 `Invalid prop: type check failed for prop "value". Expected Number with value NaN, got Undefined`，栈指向 PaginationListItem value=undefined。
- 根因：**shadcn-vue-cdn 包的 PaginationItem 渲染的是 PaginationListItem（reka-ui，`value: {type: Number, required: true}`）**，不是官方 shadcn 的 `<li>` 容器。`DataPagination.vue` 用官方 shadcn 惯例写了 4 个「PaginationItem 包 PaginationFirst/Previous/Next/Last」——这 4 个 PaginationItem 没传 value → 透传 undefined 给 PaginationListItem → 必填 Number 校验炸。页码项 PaginationItem 有 `:value="item.value"` 所以不报。
- 修复：`DataPagination.vue` 去掉 4 个导航按钮的 PaginationItem 包裹（PaginationFirst/Previous/Next/Last 是独立组件，直接放 PaginationContent 内，靠 PaginationRoot provide 取上下文），只给真正的页码项保留 PaginationItem（带 value）。
- lesson：本项目的 shadcn-vue-cdn（imohuan 的包）PaginationItem = PaginationListItem 语义（按钮 + value 必填），**不要按官方 shadcn-vue 文档那样用 PaginationItem 包导航按钮**。PaginationList 的 items 只有 page/ellipsis 两种（Gh/Hh/Uh，reka-ui utils），pageCount=1 时正常返回 [1]。
- 验证：`vue-tsc -b` ✓。
