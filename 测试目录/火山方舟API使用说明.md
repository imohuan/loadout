# 火山方舟 API 使用说明（供 AI 参考）

> 用途：调用火山引擎方舟（Ark）大模型 API 时的配置参考。
> 版本：2026-08 · cn-beijing 区域

## 1. 基本接入

- **Base URL**：`https://ark.cn-beijing.volces.com/api/v3`
- **鉴权**：`Authorization: Bearer <ARK_API_KEY>`（API Key，在控制台「API Key 管理」创建，只显示一次）
- **调用方式**：兼容 OpenAI 格式，`/chat/completions` 或 `/responses`
- **model 字段**：填接入点 ID（Endpoint ID），非模型名

## 2. 计费与免费额度

- 按 token 后付费。免费额度内实时调用**不收费**，额度耗尽后按量扣费（账户欠费会停服）。
- **免费额度抵扣范围**：在线推理输入/输出 token、缓存命中的 token、缓存未命中的 token。
- **不抵扣**：缓存存储费、批量推理（Batch）、插件/知识库费用。
- 免费额度按模型分别计算，不同模型额度独立。

## 3. 上下文缓存（重点）

缓存用于复用重复上下文（系统人设、历史对话），命中部分按折扣价计费。

### 两种模式

| | 隐式缓存 | 显式缓存 |
|---|---|---|
| 开启方式 | **自动开启，无需配置，不可关闭** | 需调 API 显式创建 |
| 缓存存储费 | **不计费** | 计费（0.000017 元/千token/小时） |
| 能否管理 | 无 ID，无法查询/删除 | 有 ID，可删除 |
| 适合 | 默认不用管 | 需要确定性命中时 |

隐式缓存：部分模型（doubao-seed-2.0 及之后等）自动生效，命中部分自动打折，**存储免费，不用管**。

### 显式缓存 API（Context API）

```
POST /api/v3/context/create
```

```json
{
  "model": "<接入点ID>",
  "messages": [
    {"role": "system", "content": "系统人设/固定背景信息"}
  ],
  "mode": "session",
  "ttl": 3600
}
```

- `mode`：`session`（默认，会话缓存，每轮动态更新）/ `common_prefix`（前缀缓存，内容固定）
- **`ttl`：缓存过期时间（秒），范围 [3600, 604800]，即 1 小时 ~ 7 天，默认 86400（24 小时）**。到期自动删除，存储费停收
- 后续对话传 `context_id` 引用缓存：
  ```
  POST /api/v3/context/chat/completions
  {"context_id": "<创建的ID>", "model": "<接入点ID>", "messages": [...]}
  ```

### 重要规则

1. **不需要手动删除缓存**：TTL 到期自动清理。日常使用只需在创建时设好 ttl。
2. **创建后 ttl 不可修改**，要改需删除重建。
3. session 缓存"用了就重置 TTL"；新对话不引用旧 `context_id` 即不续命。
4. 新开窗口对话 = 不传旧 `context_id`，天然不命中旧缓存，无需任何清理动作。
5. 显式缓存的删除接口（需要时）：
   ```
   DELETE /api/v3/responses/{response_id}   # 仅 Responses API 方式
   ```
   Context API 创建的缓存**不支持手动删除**，只能等 TTL 过期。
6. **官方没有"列出我的缓存"的 API**。如确需管理，只能自己记录创建的缓存 ID。

## 4. 推荐配置（简单场景）

- 每次开新窗口、不跨天复用的对话：**ttl 设 3600（1 小时）**，用完自动过期，成本最低。
- 无需缓存时：**直接调用普通 chat 接口**，不调 context/create 即可，零存储费。
- 长上下文反复使用（固定模板/质检/开场白）：开缓存 + 命中折扣，省钱明显。

## 5. 常见错误

| 现象 | 原因 |
|---|---|
| 429 SetLimitExceeded | 超出免费额度/推理限额，服务暂停 |
| 404 | 模型未开通，或缓存已过期/删除 |
| InvalidParam | ttl 超出 [3600,604800] 或参数错误 |
